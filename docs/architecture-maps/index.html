Cách đọc và tương tác
  • Click một thành phần để xem vai trò, các kết nối và nguồn code. Link nguồn mở đúng file/dòng tại commit đã pin trên GitHub và cần mạng; metadata nguồn nằm sẵn trong HTML.
  • Dùng +/− để zoom; kéo khi phóng to, 0 để đặt lại. Mở hướng dẫn bằng ?; dùng Escape để đóng các bảng.
  • Xuất cho phép tải PNG hoặc SVG về máy; T đổi nền sáng/tối. Một số công cụ nâng cao của viewer vẫn dùng tiếng Anh.
  • Chuyển động là minh họa đường nối đã vẽ, không phải traffic hoặc thời gian đo thực tế. Các file HTML không tải source lên dịch vụ ngoài.
Khi nào cần cập nhật?
  • Khi thay đổi route/module, Worker bindings, DB schema, importer, quy tắc Search hoặc lệnh CI/CD. Đọc lại source liên quan, cập nhật JSON và commit nguồn được dẫn chứng, rồi render/QA lại.
  • Mỗi sơ đồ chỉ tập trung vào một câu hỏi. Giữ nội dung sâu trong thẻ/nguồn; thêm node khi nó làm rõ trách nhiệm hoặc ranh giới thực tế.
  • Xem hướng dẫn tái tạo và audit Archify, license và validation. Tool nằm trong project; người xem HTML không cần cài Archify.
